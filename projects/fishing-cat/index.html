Fishing Cat

A small assistant named after the fishing cat, Odisha’s state animal. It is a LoRA on Llama-3.2-1B-Instruct, trained in 4-bit on hand-written question and answer pairs about who built it, where it is from, and how it should talk.

What the run does.

Restart first

Section 2 of the notebook is a separate project. Restart the Colab runtime if Polar Orca was trained in the same session.

Data

The notebook writes 201 recovered pairs. Non-breaking spaces in the old export are normalized to ordinary spaces. A Drive file named train_data.json replaces that set when it is present.

Holdout

“Tell me a riddle.” is removed from training. After the run, the notebook prints the expected answer beside what the model says.

Train

Loss is masked to assistant replies, using the Llama 3 header markers. Three epochs on a few hundred short pairs will memorize a voice. That is the point of this one, and the limit of it.

What this does not proveThere is no score against the base model, and the adapter is saved to Google Drive, not published as a general Hugging Face model. A friendly answer about Odisha is a smoke test. It is not evidence of a better Llama.

Decisions.

Why Llama-3.2-1B

Small enough to fine-tune in 4-bit on a free T4, and already able to follow a short chat. Fishing Cat is a voice on top of that, not a new base model.

Why hand-written pairs

The answers name Rajiv Buda and Odisha on purpose. A scraped corpus would not teach that, and it would be harder to say what the model was shown.

Why responses only

The earlier trainer learned the user lines as well as the answers. Masking the user turns spends the loss on the reply.

Why it stays local

The adapter is saved to MyDrive/fishing-cat-lora. Publishing it would imply a model someone should rely on. This one is a reproducible exercise.
