What the run does.

Restart first

Section 2 is a separate project. Restart the Colab runtime if Polar Orca already ran in the session.

Write the pairs

The notebook recovers 201 hand pairs. Non-breaking spaces are normalized. A Drive file named train_data.json replaces that set when present.

Hold one out

“Tell me a riddle.” leaves training. After the run, the notebook prints the expected answer beside the model’s reply.

Train the voice

Loss is masked to assistant replies. Three epochs on a few hundred short pairs will memorize a voice. That is the point — and the limit.

What this does not proveThere is no score against the base model. The adapter saves to Google Drive, not as a general Hub model. A friendly answer about Odisha is a smoke test — not evidence of a better Llama.

Decisions.

Why Llama-3.2-1B

Small enough to fine-tune in 4-bit on a free T4, and already able to follow a short chat. Fishing Cat is a voice on top of that, not a new base.

Why hand-written pairs

The answers name Rajiv Buda and Odisha on purpose. A scraped corpus would not teach that, and it would be harder to say what the model was shown.

Why responses only

Masking the user turns spends the loss on the reply — not on memorizing the questions.

Why it stays local

Saved to MyDrive/fishing-cat-lora. Publishing it would imply a model someone should rely on. This one is a reproducible exercise.
