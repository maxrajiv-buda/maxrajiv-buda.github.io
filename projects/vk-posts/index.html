VK public posts

A short Colab cell that reads recent public wall posts from one VK community through the official API. It is a first look at public text, not a scraper and not a dataset by itself.

How to run it.

1. Add the secret

In Colab, add a secret named VK_TOKEN. The notebook reads it at runtime and never writes it into the file.

2. Pick a public community

DOMAIN is the community screen name. The sample is ru_mash. Change it to another public wall. Posts with no text are skipped.

3. Read, don’t collect

The cell prints the date and the first 280 characters of each public post. It does not save a file, log in as a user, or request private data.

4. Stop there

If the token is missing, the cell stops with a message. It does not fall back to a hard-coded credential.

LimitThis is a public-read utility. It is not a crawler, it does not bypass access controls, and a printed post is not a training set until you decide, separately, that you have the right to use it.

The call.

DOMAIN = "ru_mash"  # public community screen name
COUNT = 10
token = userdata.get("VK_TOKEN")
vk = vk_api.VkApi(token=token).get_api()
posts = vk.wall.get(domain=DOMAIN, count=COUNT)
